# Del Surco - Frontend Estático

Sistema frontend modular desarrollado en HTML5 y CSS3 puro, estructurado con IDs y atributos listos para la integración con los endpoints de la API.

## 📁 Estructura del Proyecto

```text
hackathon/
│
├── index.html                 # Vista principal / Inicio de sesión (Login)
├── css/
│   ├── styles.css             # Estilos globales y de Login
│   ├── registro.css           # Estilos para la selección de roles
│   ├── registro-comprador.css # Estilos para el formulario de comprador
│   └── registro-vendedor.css  # Estilos para el formulario de vendedor
├── html/
│   ├── registro.html          # Vista de selección de perfil (Comprador / Vendedor)
│   ├── registro-comprador.html# Formulario de registro de comprador
│   └── registro-vendedor.html # Formulario de registro de vendedor
├── image/                     # Recursos gráficos y logos
└── icon/                      # Iconos institucionales
